# 窗格控制器按状态持有者切开，布局事务留在内核

内核（`dsh-pane-host.js`）保留布局簿、面板引用保留、唯一的 `apply()` 事务与快照的冻结广播；右栏、关闭流、窗格上限各自持有寄存器，通过 `snapshotPatch()` 上报自己拥有的字段，`emit()` 在调用方补丁之后合并它们。面与模块不一一对应（`pane-layout.js` 同时出 `layout` 与 `view` 两个面），布局事务与工作区生命周期故意留在内核——切开会造出两个共享 `book` 的模块，那是假接缝。结果是 face 从 41 键降到 18 键、内核 1506 行仍超 600 行上限；行数不是验收口径，接口变深才算。

**状态**：accepted
