# 首个能力：多会话分屏 + 侧栏精简（窗格 ⇄ 会话 1:1）

需求收敛为三件事：侧栏只留工作区名与状态灯、用 `/resume` 与 `/clear` 替代侧栏对话列表、主区域支持任意分割。每个窗格承载**恰好一个**会话，每个工作区一棵布局树且树上只装本工作区的会话，标签条只是窗格索引；侧栏工作区区块整块替换，`/clear` 与 `/resume` 是纯客户端命令。分屏通过 shadow `main` 的 `conversation` 接管主区域（最初的 `selectPanel` 方案已被 ADR-0014 取代），代价是跨工作区不能同屏、刷新后不恢复滚动位置与未发送草稿。

**状态**：accepted
