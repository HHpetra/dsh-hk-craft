# 05: 布局树：分割、关闭、焦点、比例

**What to build:** 一个工作区里可以把对话摆成任意的横竖嵌套布局。用户对某一格执行「向右分割」或「向下分割」，就在旁边开出一格并立即开一个新会话；关闭一格时它的兄弟节点顶替父节点的位置；正在输入的那一格有可见的焦点描边；分隔条可拖动且每格不会被拖到不可用。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 支持横向与纵向任意嵌套分割（不是固定网格，也不是三档固定模式）
- [ ] 分割出的新格立即拥有一个新会话，可直接发消息
- [ ] 关闭一格后结构归一：兄弟顶替父节点位置，不留空白格；焦点移到邻近格
- [ ] 焦点格有清晰描边；点击窗格任意处即聚焦
- [ ] 焦点切换后，dsh 认知的「当前会话」跟着变成该格的会话（不出现两个当前会话）
- [ ] 分隔比例可拖动，每格有最小尺寸限制，拖动后不塌陷
- [ ] 窗格内容在布局变化时不卸载（流式输出、滚动位置、输入草稿不丢）

状态形状以 spec 第 4.1 节为准，实现时保持这个类型形态（决策密集部分，勿改语义）：

```ts
type LayoutNode =
  | { kind: "leaf"; paneId: string }
  | { kind: "split"; dir: "row" | "col"; ratio: number; a: LayoutNode; b: LayoutNode };
```
