# 04: 单窗格挂载（分屏地基）

**What to build:** 主区域不再由 dsh 原生的单会话视图独占，而是可以被插件接管：接管后显示一个窗格，里面是**指定会话**的完整可交互对话——能发消息、能看到流式回复、能用停止按钮。同时必须能一键切回 dsh 原生界面，且原生界面行为不受影响。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 插件能激活自己的主区域面板，在其中为某个明确指定的会话渲染完整对话（不是只读快照）
- [ ] 在该窗格内发消息能正常得到回复；流式输出正常；停止按钮可用
- [ ] 可切回 dsh 原生对话视图，原生视图的一切行为与未装插件时一致
- [ ] 启动时对 `conversation.content` 这个 Factory 做特性探测；缺失时退化为「单对话 + 明确提示」，不出现白屏或静默失败
- [ ] 同一会话在同一时刻不会被挂载两次（不与原生视图并存）
- [ ] 面板注销（如卸载插件）后自动回到原生视图，不需要手工清理
