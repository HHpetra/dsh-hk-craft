# 08: 工作区隔离与布局持久化

**What to build:** 每个工作区有自己的一套窗格布局，互不干扰。切换工作区只换「看见哪些窗格」，不关闭任何窗格、不打断任何会话；切走期间会话继续在后台跑。关闭浏览器或重启 dsh 后，每个工作区的树形、分隔比例、焦点格和每格视图都原样恢复。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 三个工作区各有独立布局，切换时互不覆盖
- [ ] 切走再切回：布局、焦点、滚动位置、输入草稿全部恢复
- [ ] 切走期间会话继续运行；切回后能看到这期间产生的完整输出
- [ ] 重启 dsh 后每个工作区的树形、比例、焦点、每格视图复原
- [ ] 恢复时若某格绑定的会话已不存在，丢弃该格并把树规范化；树为空则显示空态
- [ ] 布局状态的存储键按工作区区分，不会跨工作区串味
