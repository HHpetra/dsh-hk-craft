# 09: 关闭窗格即中断会话

**What to build:** 关闭一个窗格时，如果里面的会话正在跑，先确认再中断它并把会话释放掉；会话本身不会消失，历史还在，之后可以经 `/resume` 重新拉回某个窗格。取消关闭则什么都不发生。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 先查清插件侧可用的中断入口（spec 第 12 节 G2），把结论写进本票 Comments，再动手实现
- [ ] 关闭正在运行的窗格：弹出确认，文案说明「会话将被中断并保留在历史中」
- [ ] 确认后回合被真正中断（不是仅停止刷新），无孤儿流、无重复订阅
- [ ] 取消关闭：会话继续运行，窗格不受影响
- [ ] 关闭空闲窗格不弹确认，直接关闭
- [ ] 被关闭的会话随后可从 `/resume` 重新打开并继续对话
