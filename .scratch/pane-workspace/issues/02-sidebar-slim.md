# 02: 侧栏工作区区块精简

**What to build:** 侧栏里每个工作区只显示一个状态灯和名称，不再列出任何会话、不提供展开与折叠；底部保留唯一的「添加工作区」。点击工作区照常切换。侧栏其余部件（品牌区、折叠开关、Plugins／自动化图标行、More 菜单、Settings、底部动作）保持原样，行为不变。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 工作区行只含状态灯与名称；无会话行、无会话行悬停操作、无分组模式切换、无折叠、无归档筛选、无区块内搜索
- [ ] 状态灯三态正确且优先级为红 > 黄 > 绿：红=有会话在等你（审批／追问）或出错，黄=有会话运行中，绿=无活动会话
- [ ] 「添加工作区」仍可创建并选中新工作区；点击已有工作区仍能切换
- [ ] 侧栏其余部件与原生行为完全一致（含窄屏折叠）
- [ ] 卸载并重启后侧栏恢复原生形态，无残留样式或空槽
