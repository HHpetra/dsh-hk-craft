# 07: 窗格视图开关（对话 / 轨迹）

**What to build:** 每个窗格的右上角出现一个「对话 | 轨迹」分段开关，点一下就切换该格显示的内容，另一格不受影响。原生那排「对话／轨迹」大按钮不再重复出现。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 每个窗格都有独立的分段开关，切换即时生效
- [ ] 视图选择按窗格记忆：两格可以一格看对话、一格看轨迹，互不影响
- [ ] 原生对话标题区那排视图按钮不再出现在窗格内
- [ ] 轨迹视图不可用时（开发者工具关闭），开关相应禁用，行为与原生过滤一致
- [ ] 切换视图不重建会话、不丢滚动位置与草稿
