# 10: 打磨

**What to build:** 把多窗格从「能用」做到「顺手」：把一个标签拖到另一个标签上就交换两格的内容（布局形状不变）；一个窗格都没有时给出空态引导；快捷键覆盖常用动作且界面提示与实际一致；状态点变化时不抖动。

**Blocked by:** 06, 07, 08, 09

**Status:** ready-for-agent

- [ ] 拖动标签到另一标签上交换两格的会话内容，树形状与比例保持不变；拖到空白处不产生任何副作用
- [ ] 空态：无窗格时显示引导，可直接新建会话，或从最近会话里挑一个打开
- [ ] 快捷键覆盖聚焦第 N 格、分割、关闭、新会话，且界面提示文案与实际键位一致
- [ ] 状态点在运行／等待／出错之间切换时不引起布局跳动
- [ ] 焦点描边、标签高亮、悬停关闭在浅色与深色主题下都清晰可辨
