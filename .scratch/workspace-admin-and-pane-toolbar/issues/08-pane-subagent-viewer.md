# 08: 子代理查看入口

**What to build:** 在标签条右侧的原生操作组里提供子代理查看入口，作用于焦点窗格会话。入口显示直接子会话总数与运行中数量；没有目录或目录为空时隐藏。点开后列出直接子会话的名字、模式和活动状态；选择一项就在新窗格打开它，已经在窗格中则聚焦它。下拉打开时刷新一次目录；按 Escape、点外部或选择后关闭，并把焦点还给入口。外部任务行不可导航，与原生一致。

**Blocked by:** 06 — 标签条工具栏骨架

**Status:** ready-for-agent

- [ ] 右侧组的子代理扩展位显示直接子会话总数与运行中数量；目录不存在或为空时不渲染入口。
- [ ] 下拉列出直接子项：名字（缺失时退回 id）、模式（continuable / one-shot / unknown / external，本地化）、活动状态（运行中/已完成/空闲，外部行不显示活动）。
- [ ] 外部任务行不可点击；其余行选择后在新的窗格中打开该子会话，若已经打开则聚焦已有窗格，并关闭下拉。
- [ ] 打开下拉时刷新一次父会话的子代理目录；刷新失败不阻塞展示。
- [ ] 入口可用 Tab 到达、Enter/Space 打开；Escape 或点击外部关闭并把焦点还给入口。
- [ ] 只实现直接子会话；嵌套展开、悬停展开、失败重试、父级面包屑不在本票内。
- [ ] 纯工具栏投影测试覆盖：目录缺失/为空时隐藏、计数与运行中计数、活动状态来自状态映射并有汇总行回退、外部行标记不可导航。
- [ ] 上游契约页记录子代理目录的读取位置、刷新能力与在新窗格打开会话的公开路径。
