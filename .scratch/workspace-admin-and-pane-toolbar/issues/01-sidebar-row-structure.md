# 01: 侧栏工作区行结构预重构

**What to build:** 把侧栏的工作区行从「整行一个按钮」改成「行容器 + 主选择按钮 + 行内动作位」。用户看到的行外观和行为保持不变：点击仍打开/切换工作区，键盘仍可聚焦触发，当前工作区高亮、灯和名称都不变。动作位当前为空或不可见，但为后续删除入口提供独立、非嵌套的落点；行容器也为拖动排序留好手势入口。这是纯预重构，不新增用户可见功能。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 点击行仍打开或切换到对应工作区：分屏内切换可见布局，分屏外走原生揭示路径。
- [ ] 行仍可用键盘聚焦并触发；当前工作区高亮、灯色、名称与修改前一致。
- [ ] 行内存在独立动作位，主选择控件与动作位不是嵌套按钮；动作位有稳定的标记，后续票可以无歧义地让拖动忽略它上面的指针按下。
- [ ] 现有单元测试全绿；没有新增用户可见行为。
- [ ] 行的可访问名仍包含工作区名与灯色说明。
