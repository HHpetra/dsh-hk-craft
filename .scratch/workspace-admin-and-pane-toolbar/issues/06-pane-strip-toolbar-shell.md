# 06: 标签条工具栏骨架

**What to build:** 把分屏的标签条改造成工具栏骨架：左边是可横向滚动的标签区，新增会话按钮紧跟在最后一个标签之后，不再右对齐；右边是一个固定、不参与滚动的原生操作组，先占位并留出“当前模式”和“子代理”两个独立扩展位。标签很多时先截断标签，右侧组始终不收缩、不被裁掉。本版不提供“打开右侧边栏”按钮。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 标签条结构为：外层条 + 可横向滚动视口（标签区 + 紧跟的新增会话按钮）+ 视口之外的固定右侧操作组。
- [ ] 新增会话按钮紧贴最后一个标签；标签少时紧跟、标签多时随标签一起滚动；不再占据最右侧。
- [ ] 右侧操作组包含两个独立扩展位：当前模式、子代理；组本身只负责排列与不收缩，两个扩展位可以各自独立填充（后续票可并行）。
- [ ] 标签标题先截断；模式与子代理控件有各自的最大宽度；极窄宽度下右侧组仍完整可见。
- [ ] 标签区仍可键盘操作，现有快捷键（聚焦第 N 格、新开、关闭）不回归。
- [ ] 本版不出现“打开右侧边栏”按钮，也不放 jobs、open-in-app、schedule、会话日志等原生头部件。
- [ ] 上游契约页记录：分屏面板激活时原生右侧边栏被隐藏、其“当前会话”为空，因此本版暂缓右侧边栏；右侧组是未来原生工具的预留位置。
- [ ] 视觉冒烟：1 个、2 个、5 个标签时新增会话按钮都紧贴最后标签；空工作区的空状态不显示工具栏。
