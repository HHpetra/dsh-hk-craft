# 04: 工作区拖动排序

**What to build:** 工作区行可以拖动排序。指针移动超过 6px 才进入拖动状态，普通点击仍然是打开工作区；拖动结束后那一次 click 被吞掉。落点按目标行上下半部决定：上半部插到该行之前，下半部插到该行之后，最后一行的下半部追加到末尾。拖动时显示插入指示线，源行降低不透明度。排序写入 Host 的工作区顺序，重启后保留；失败时显示错误并回到 Host 已提交的顺序。排序不改变当前工作区、焦点或窗格内容。

**Blocked by:** 01 — 侧栏工作区行结构预重构

**Status:** ready-for-agent

- [ ] 拖动超过 6px 才进入排序状态；未超过阈值的按下仍按点击打开工作区；拖动后的 click 不触发打开。
- [ ] 动作位上的指针按下不启动拖动（与删除入口并行实现时互不干扰）。
- [ ] 落点支持：插到目标之前、插到目标之后、最后一行的下半部追加到末尾；放回原位、源与目标相同、未知目标都是无操作。
- [ ] 拖动期间显示插入指示线；排序请求进行中禁止再次拖动。
- [ ] 排序调用 Host 的持久化顺序能力；失败时显示错误，界面顺序回到 Host 已提交的顺序。
- [ ] 排序不改变当前工作区、焦点或窗格内容；行顺序始终直接来自 Host 的工作区列表，侧栏不自己排序或缓存。
- [ ] 纯落点函数单元测试覆盖前/后/追加/原位/源等于目标/未知 id/空列表/单元素列表。
- [ ] 适配层测试覆盖“前/后”到 Host 锚点的换算（含追加）、失败上抛。
- [ ] 上游契约页记录工作区顺序的 Host 持久化语义、锚点缺省表示追加、客户端乐观排序与失败恢复。
