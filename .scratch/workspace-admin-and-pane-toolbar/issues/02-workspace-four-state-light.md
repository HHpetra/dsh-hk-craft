# 02: 工作区四态灯

**What to build:** 侧栏工作区灯从三态扩展为四态：灰、绿、黄、红。灰表示该工作区从没在分屏里打开过（未启用），或已启用但还没有任何对话结束；绿只表示至少有一段已开始（非空白）且当前空闲的对话；黄表示有会话运行中；红表示有会话等你操作。优先级为红 > 黄 > 绿 > 灰。进入某个工作区的分屏后，该行灯色应立即变化，无需刷新页面。

**Blocked by:** 01 — 侧栏工作区行结构预重构

**Status:** resolved

- [ ] 未启用判定：既没有已加载的窗格布局、也没有持久化布局记录的工作区显示灰灯；在原生视图里打开工作区不算启用。
- [ ] 已启用且任一成员等待用户（审批、提问、计划确认）显示红灯；任一成员运行中显示黄灯；至少一个成员非空白且没有运行/等待显示绿灯；只有空白新会话显示灰灯。
- [ ] 优先级为红 > 黄 > 绿 > 灰；已归档会话不参与判断；会话列表里已不存在的会话被跳过。
- [ ] 工作区快照未就绪时不产生行；会话列表未就绪时无法证明“对话已结束”，全部按灰处理；没有启用集合时降级为全部视为已启用，只按会话推导绿/灰。
- [ ] 进入某个工作区的分屏后，该行灯色立即从灰变为对应状态；重启 dsh 后，持久化布局键仍让该工作区保持“已启用”。
- [ ] 行仍把工作区名与灯色一起暴露给读屏；四态的中英文案键集合一致，绿色文案不再使用“无活动会话”。
- [ ] 没有“错误灯”：不读取失败位，也不打开会话历史。
- [ ] 单元测试覆盖四态各一例、优先级、未启用、空白会话、归档/未知会话、未就绪快照、空启用集合与降级语义。
- [ ] 上游契约页记录 `blank` 的含义与“启用 = 有窗格布局记录”的判定，并注明原生视图打开不算启用。
