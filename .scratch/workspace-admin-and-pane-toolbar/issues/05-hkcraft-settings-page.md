# 05: HK Craft 设置页与移除临时按钮

**What to build:** 侧栏 footer 不再出现诊断和分屏切换这两个临时按钮；设置面板新增独立的 HK Craft 页。页内直接展示诊断信息（客户端是否加载、入口名、`conversation.content` 探测结果、当前是原生视图还是分屏），并提供临时的分屏开关：可以进入分屏窗格，也可以回到原生视图；成功切换后关闭设置页，失败则在页内显示原因。旧的浮动诊断面板移除。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 侧栏 footer 不再注册或渲染诊断按钮与分屏切换按钮。
- [ ] 设置导航出现独立的 HK Craft 分区，标签跟随界面语言，位置排在官方分区之后。
- [ ] HK Craft 页展示：客户端已加载、入口名、`conversation.content` 探测状态与消息、当前视图（原生/分屏）。
- [ ] 页内分屏开关读取窗格控制器快照：未激活时显示“进入分屏窗格”，激活时显示“回到原生视图”；切换中禁止重复提交。
- [ ] 分屏切换成功后关闭设置页；失败时在页内显示原因且设置页不关。
- [ ] 不再存在浮动诊断面板；诊断内容直接排在设置页里。
- [ ] 设置页只依赖槽、locale 和控制器闭包；缺少设置能力时该页安静缺席，不影响其他功能。
- [ ] 中英文案键集合一致；入口注册与设置页组件工厂有单元测试。
- [ ] 上游契约页记录设置分区槽的注册形态、组件收到的关闭回调、导航标签随语言刷新。
- [ ] 说明文案明确：这两个是过渡入口，长期入口确定后会移走。
