# 07: 当前模式只读标签

**What to build:** 在标签条右侧的原生操作组里显示焦点窗格会话的当前模式（只读）。它跟随焦点窗格切换，显示该会话启动时选择的 Agent 预设；自定义预设显示自己的名字，内置预设显示本地化名字，未知预设退回 id；没有焦点会话或没有记录预设时不显示。标签不可点击，也不尝试切换预设。

**Blocked by:** 06 — 标签条工具栏骨架

**Status:** ready-for-agent

- [ ] 右侧组的模式扩展位显示焦点会话的预设标签；点击其他标签或窗格后标签跟着切换。
- [ ] 数据来自会话汇总里的预设标识，与原生头部标签同源。
- [ ] 名称解析优先级：名册里的自定义名 > 四个内置预设的本地化名 > 原样 id。
- [ ] 名册通过可选能力读取；名册失败、服务缺失、结果畸形时安静降级到本地名或 id，不阻塞工具栏渲染。
- [ ] 没有焦点会话或没有预设记录时不渲染该标签，右侧组不保留空位。
- [ ] 标签不可点击，不写会话状态；`title` 使用预设描述（若有）或一句“该会话启动时选择的模式”。
- [ ] 纯工具栏投影与预设名解析有单元测试，覆盖自定义/内置/未知/名册失败/名册缺失。
- [ ] 上游契约页记录会话汇总的预设字段与名册读取的可选性。
